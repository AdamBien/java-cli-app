# java-cli-app

Template project for building zero-dependency Java CLI applications with [zb](https://github.com/AdamBien/zb). Part of the [bce.design](https://bce.design) and [airails.dev](https://airails.dev) ecosystem.

## Prerequisites

Java 25+, [zb](https://github.com/AdamBien/zb)

## Build and Run

```
zb
java -jar zbo/app.jar
```
